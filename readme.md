# AI-HR4U Backend (Django + DRF)

This is the backend API for **AI-HR4U**, built with Django and Django REST Framework. It includes company verification APIs and is deployed on Render with PostgreSQL as the database.

---

##  Live API

- **Base URL**: https://aihr4u.onrender.com
- **Verify Company Endpoint**: `api/verify-company?query=YourCompanyName`

---

##  Tech Stack

- Python 3.11+
- Django 5.x
- Django REST Framework
- PostgreSQL (Render)
- `django-cors-headers`
- Hosted on Render.com
